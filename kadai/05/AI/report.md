# プロンプトエンジニアリング課題レポート

## 課題

「1から100までの素数を出力する」プログラムを作成するプロンプトを改善し、最適なものを選定する。

---

## 試したプロンプト一覧

### プロンプト1: 基本形

```
素数を見つけるプログラム書いて
```

**問題点**:
- プログラミング言語が指定されていない
- 範囲（1〜100）が指定されていない
- 出力形式が不明確
- 解説がつくかどうか不明

### プロンプト2: 形式指定

```
Pythonで1から100までの素数を見つける関数を実装してください。
素数のリストを返す関数として実装し、使用例も示してください。
```

**改善点**:
- 言語をPythonに指定
- 範囲を1〜100に明確化
- 関数形式・戻り値の形式を指定

**残る問題点**:
- アルゴリズムの選択がLLM任せ
- コードの説明・解説が不十分になる可能性

### プロンプト3: アルゴリズム説明要求

```
1から100までの素数を出力するPythonプログラムを書いてください。
使用するアルゴリズムの計算量と、なぜそのアルゴリズムを選んだか説明してください。
```

**改善点**:
- アルゴリズムの説明を要求
- 計算量の解説が含まれる

**残る問題点**:
- 関数名や実装の詳細が不明確
- コード内コメントの有無が不明

### プロンプト4: 詳細指定（採用）

```
以下の要件でPythonプログラムを書いてください：

【タスク】1から100までの素数を出力する

【要件】
- 関数名: find_primes(n)
- 引数nまでの素数をリストで返す
- エラトステネスの篩アルゴリズムを使用
- 各ステップにコメントを付ける
- 実行例と出力結果も示す

【解説についても記載】
- なぜエラトステネスの篩が効率的か
- 時間計算量と空間計算量
```

## 最も良かったプロンプト

**プロンプト4（詳細指定）** を採用しました。

### 選定理由

1. **曖昧さの排除**: 言語、関数名、アルゴリズム、出力形式をすべて明示することで、LLMが推測する余地を減らし、意図通りの出力を得られる

2. **教育的価値**: アルゴリズムの説明と計算量の解説を要求することで、単なるコード生成ではなく学習教材としても使える出力が得られる

3. **再利用性**: `find_primes(n)` という汎用的な関数インターフェースを指定することで、100以外の範囲でも使える設計になる

4. **保守性**: コメントを要求することで、後から読み返しても理解しやすいコードが得られる

## 出力されたコードと説明

### コード

```python
def find_primes(n):
    """
    エラトステネスの篩を使用して、n以下の素数をすべて見つける

    Args:
        n: 探索する上限値
    Returns:
        n以下の素数のリスト
    """
    # n以下の場合は素数なし
    if n < 2:
        return []

    # 篩を初期化（インデックス0からnまで、最初はすべてTrue）
    # is_prime[i] = True は、iが素数の候補であることを示す
    is_prime = [True] * (n + 1)
    is_prime[0] = False  # 0は素数ではない
    is_prime[1] = False  # 1は素数ではない

    # エラトステネスの篩のメインループ
    # 2からsqrt(n)までの各数について、その倍数を除外する
    i = 2
    while i * i <= n:
        if is_prime[i]:
            # iの倍数（i*i, i*i+i, i*i+2i, ...）をすべて非素数としてマーク
            # i*iから始めるのは、それより小さい倍数は既にマーク済みのため
            for j in range(i * i, n + 1, i):
                is_prime[j] = False
        i += 1

    # 素数のリストを作成して返す
    primes = [num for num in range(2, n + 1) if is_prime[num]]
    return primes


# 実行例
if __name__ == "__main__":
    result = find_primes(100)
    print(f"1から100までの素数（{len(result)}個）:")
    print(result)
```


## アルゴリズムの解説

### エラトステネスの篩とは

古代ギリシャの数学者エラトステネスが考案した、素数を効率的に見つけるアルゴリズム。

**動作原理**:
1. 2からnまでの整数リストを用意
2. 最小の数（2）から始めて、その倍数をすべて消す
3. 次に残っている最小の数の倍数を消す
4. sqrt(n)まで繰り返す
5. 残った数がすべて素数

### なぜ効率的か

**単純な方法との比較**:
- 単純な方法: 各数nに対して2からsqrt(n)まで割り切れるかチェック → O(n√n)
- エラトステネスの篩: O(n log log n)

**理由**:
- 一度の操作で複数の合成数を効率的に除外できる
- 倍数を除外する際、既に小さい素数で除外済みの数はスキップできる

### 計算量

| 項目 | 計算量 |
|------|--------|
| 時間計算量 | O(n log log n) |
| 空間計算量 | O(n) |

## 改善のポイントまとめ

### 何を追加/変更したか

| 項目 | 基本プロンプト | 改善後プロンプト |
|------|---------------|-----------------|
| 言語指定 | なし | Python |
| 範囲指定 | なし | 1から100（引数で可変） |
| 関数名 | 不明 | `find_primes(n)` |
| アルゴリズム | LLM任せ | エラトステネスの篩を指定 |
| コメント | 不明 | 各ステップにコメント |
| 解説 | なし | 計算量・効率性の説明 |

### なぜその改善が必要だったか

1. **再現性の確保**: 同じプロンプトで毎回同じ品質の出力を得るため
2. **学習効果**: コードを読むだけでアルゴリズムを理解できるようにするため
3. **実用性**: 他のプロジェクトでも再利用できる汎用的な設計にするため

### 期待される出力の違い

| 観点 | 基本プロンプト | 改善後プロンプト |
|------|---------------|-----------------|
| コード品質 | 動くだけ | 読みやすく保守しやすい |
| 教育的価値 | 低い | 高い（理由・計算量の説明あり） |
| 汎用性 | 固定値のみ | 引数で範囲を変更可能 |
| 一貫性 | 実行ごとにバラつき | 要件が明確で一貫した出力 |

## 結論

プロンプトエンジニアリングにおいて重要なのは、**曖昧さを排除し、期待する出力の形式・内容を具体的に指定すること**である。

特に以下の点を明示することで、LLMからより高品質な出力を得られる:
- プログラミング言語
- 関数/クラスのインターフェース
- 使用するアルゴリズムや手法
- コメント・ドキュメントの要求
- 解説・説明の要求

「良いプロンプト = 良い仕様書」と考えると分かりやすい。
